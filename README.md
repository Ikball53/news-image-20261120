# The World in One Picture — 20 November 2026

Entry for make.fun's "Sum up 20 November's world news in one image" bounty.

`main.py` copies the bundled `entry.png` (1024×1024) to the output directory.
The image sums up Friday 20 November 2026 in eight dated story cards —
diplomacy, justice, markets, war, the Middle East, weather, Europe and
Asia — with a world map on the right marking each story's location.
