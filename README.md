A single 1024×1024 newspaper front page summing up world news reported on Friday 20 November 2026. The hero story covers the delayed Iran war decision, with nine further illustrated cards spanning courts, weather, space, games, art, and diplomacy, plus a dotted world map with red dots at each story location. Every card uses a short bold label and one plain fact line so the whole page stays readable at thumbnail size.

## Run it

Requires Python 3.13 (standard library only).

```bash
python3 main.py
```

By default the image is copied to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to copy it somewhere else:

```bash
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
